# CyberCraft

Сайт команды веб-разработки: услуги, портфолио, примеры сайтов и информация об участниках. Тёмное оформление с оранжевыми акцентами, интерактивный 3D-фон и адаптивная вёрстка.

## Ссылки

- [Репозиторий проекта](https://github.com/bobojonanaev2-code/ysmteam)
- [Сайт на GitHub Pages](https://bobojonanaev2-code.github.io/ysmteam/)
- [Запуски публикации в GitHub Actions](https://github.com/bobojonanaev2-code/ysmteam/actions)

**Версия на GitHub Pages зависит от последней успешной публикации.** Если там открывается старый дизайн, загрузите актуальные файлы сайта в репозиторий и дождитесь завершения публикации. Изменение только этого README не обновляет страницы сайта.

## Что есть на сайте

- Главная страница с услугами, проектами и шестью примерами веб-сайтов.
- Страницы команды, услуг, портфолио и контактов.
- Демонстрационные сайты о моде, путешествиях, финансах, ресторане, архитектуре и wellness — каждый со своим оформлением и содержанием.
- Оранжевая каркасная сфера с логотипом, постоянным вращением, свечением и мягкой деформацией при наведении.
- Плавное замедление прокрутки, анимации появления, параллакс и интерактивные карточки.
- Спокойный эмбиент, звуки кнопок и переключатель звука с сохранением выбора.

## Открыть локально

Откройте `index.html` из папки проекта в браузере. Для разработки можно использовать локальный статический сервер с корнем в этой папке. Сборка и установка пакетов не требуются.

Для полной загрузки оформления нужен интернет: шрифты загружаются из Google Fonts, Three.js — с CDN, часть фотографий — с Unsplash.

## Структура проекта

```text
.
├── index.html              # Главная страница
├── about.html              # Команда
├── services.html           # Услуги
├── portfolio.html          # Проекты
├── contact.html            # Контакты
├── preview.html            # Демонстрационные сайты и примеры проектов
├── css/
│   ├── style.css           # Оформление основного сайта
│   └── preview.css         # Оформление демонстрационных сайтов
├── js/
│   ├── main.js             # 3D-фон, анимации, прокрутка, звук и интерфейс
│   └── preview.js          # Содержание и логика демонстрационных сайтов
├── images/team/            # Изображения участников команды
├── .github/workflows/      # Конфигурации публикации на GitHub Pages
└── README.md
```

Основные страницы подключают `css/style.css` и `js/main.js`. В корне также находятся их копии — `style.css` и `main.js`; при изменениях их следует синхронизировать с подключаемыми файлами.

## Где менять содержимое

| Что нужно изменить | Файлы |
| --- | --- |
| Тексты, ссылки и разделы основных страниц | Соответствующий HTML-файл |
| Цвета, шрифты, отступы и адаптивную вёрстку | `css/style.css` |
| Движение шара, прокрутку, музыку и звуки | `js/main.js` |
| Содержание и поведение примеров сайтов | `js/preview.js` |
| Дизайн примеров сайтов | `css/preview.css` |
| Портреты команды | `images/team/` |

Пример сайта выбирается параметром `site` в адресе `preview.html`: `atelier`, `travel`, `finance`, `restaurant`, `architecture` или `wellness`. Карточки проектов используют параметр `project`.

## Публикация

В проекте сохранены конфигурации GitHub Actions для публикации статических файлов на GitHub Pages. Основной файл `deploy.yml` настроен на отправку изменений в ветку `main` и публикацию содержимого корня проекта.

1. Загрузите актуальные HTML-файлы, папки `css`, `js`, `images` и остальные файлы проекта в репозиторий.
2. В настройках GitHub Pages выберите публикацию через GitHub Actions. Если включены оба сохранённых процесса публикации, оставьте один используемый процесс.
3. Дождитесь успешного завершения публикации в разделе Actions. Адрес опубликованной версии выводится в окружении `github-pages`.
4. Если браузер показывает прежнее оформление, обновите страницу с очисткой кэша: **Ctrl + F5**.

## Особенности

- Музыка запрашивает запуск при открытии страницы. Если браузер запрещает автозвук, она запускается после первого клика или нажатия клавиши. Сохранённое выключение звука учитывается при следующих посещениях.
- При включённом системном уменьшении движения анимация шара ограничивается, а дополнительная инерция колеса отключается.
- Контактная форма основного сайта сейчас показывает локальное подтверждение. Для реальной отправки заявок необходимо подключить обработчик или сервис форм.
- Демонстрационные сайты показывают дизайн и интерфейсы; реальные платежи, бронирования и обработка заявок требуют отдельных интеграций.
